# Frontend Feature Skill

Use this skill for Next.js/React/TypeScript work in COMANDOS.

## Procedure
1. Read AGENTS.md and identify the target module.
2. Confirm the backend contract before inventing client behavior.
3. Reuse platform HTTP/session/preferences/UI contracts when generic.
4. Preserve existing colors, behavior, accessibility, and user-visible functionality unless the task says otherwise.
5. Handle loading, empty, error, permission, and retry states.
6. Avoid embedding business-critical security rules only in the browser.
7. Keep API models typed and aligned with backend responses.
8. Run lint, build, relevant browser/tests, platform boundary audit, and license audit when applicable.
9. Commit small, reviewable changes.

## Guardrails
- Do not introduce paid/commercial dependencies without approval.
- Do not expose secrets in NEXT_PUBLIC variables.
- Do not duplicate a platform component inside a domain without a concrete reason.
